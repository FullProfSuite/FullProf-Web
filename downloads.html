Installation Instructions

How to install and set up the FullProf Suite on your system

FullProf Suite new compilers

During 2024 two kinds of distributions will be available: one built with the classic Intel Fortran compiler (ifort) and the other built using the new Intel compiler (ifx). Bugs may appear and users are suggested to communicate misbehaviour of some programs in order to correct immediately the corresponding executable. In the future, only the version with the new compiler (ifx) will be available.

NEW! FullProfApp

FullProfApp is a new tool for automated Rietveld analysis of powder diffraction patterns using FullProf as refinement engine. This tool is designed to easily handle large chunks of diffraction data generated by high-throughput screening (HTS) experiments as well as by in situ and operando studies at large user facilities such as Synchrotron and Neutron sources.

Assumes the FullProf Suite is installed. Manual: fullprofapp.readthedocs.io.
Cite this paper when using the tool: https://doi.org/10.1107/S1600576724006885

Installation of the FullProf Suite for Windows

Download the package (executable installer) in a temporary directory and run it. Follow the indications of the installer. Avoid directories with spaces or non-ASCII characters.

Installation of the Linux-like FullProf Suite for macOS

Unzip FullProf_MacOS_XXXXXX.zip in the desired location (e.g., $HOME/FullProf_MacOS or /Applications/FullProf_MacOS). Move the “Examples” folder if necessary.

Open a terminal and set the shell (default is ZSH; for BASH: chsh -s /bin/bash). Then run Set_FULLPROF_Envi in the FullProf directory. Follow additional instructions in the script to fix permissions and environment variables.

Installation of the FullProf Suite for macOS

FullProf4Mac.app is the full implementation (64-bit). Double-click the icon to launch. Requires: macOS High Sierra (10.13) or higher, XQuartz v2.7.9 or higher.

Drag the app into the Applications folder. Known minor bugs may appear due to XQuartz or macOS APIs.

Installation of the FullProf Suite for Linux

Download the version you want from the website. General mode (all users) or Local mode (single user) instructions are provided. Activate the environment variable FULLPROF in your shell configuration file.

Ensure OpenMotif libraries are installed if a GUI fails with messages like “libXm.so.3 not available”.
